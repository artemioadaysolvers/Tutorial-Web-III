# Tutorial-Web-III

Tutorial III para desarrollo de una aplicación web para manipular un NVIDIA Jetson con conexión a internet.

Este tutorial tiene como objetivo enseñar a desarrollar y desplegar una aplicación web que permita monitorear, configurar y administrar remotamente una NVIDIA Jetson conectada a Internet, utilizando React, TypeScript y Next.js para el desarrollo del frontend, Python para la comunicación y ejecución de procesos en el dispositivo, y Microsoft Azure como plataforma de alojamiento y comunicación en la nube.

La aplicación incorporará un sistema de autenticación de usuarios, mediante el cual se podrá acceder a un panel de control para visualizar el estado de la NVIDIA Jetson, consultar sus recursos computacionales y modificar parámetros de los algoritmos de inteligencia artificial ejecutados en el dispositivo, como modelos de detección de objetos mediante YOLO.

Por ejemplo, desde la página web será posible ajustar el umbral de confianza del modelo, configurar la frecuencia de procesamiento de imágenes, iniciar o detener procesos de inferencia y consultar los resultados generados por el dispositivo.

Para permitir la administración remota, se implementará una arquitectura de comunicación segura entre el servidor web alojado en Microsoft Azure y un agente desarrollado en Python que se ejecutará en la NVIDIA Jetson.

Asimismo, el tutorial enseñará a utilizar Git para administrar el repositorio y GitHub Actions para automatizar los procesos de compilación y despliegue de la aplicación web en Microsoft Azure.

El propósito final es introducir a los participantes en el desarrollo de aplicaciones web integradas con sistemas físicos e inteligencia artificial, combinando tecnologías frontend, backend, computación en el borde (Edge Computing), servicios en la nube y automatización de despliegues
